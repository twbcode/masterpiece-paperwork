# Masterpiece Paperwork

The office program for Masterpiece Construction Experts: handwritten estimate → typed estimate → sales contract → final invoice, all as PDFs.

- Open it in Chrome or Edge on a computer: https://twbcode.github.io/masterpiece-paperwork/
- Customer jobs and the blank company forms are saved only in the folder chosen on that computer. Nothing about customers is stored on this website.
- The handwriting reader uses the office's own Claude API key, saved only on that computer (Settings → Handwriting reader).
